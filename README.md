# LeaseLens

Upload your lease and ask questions about it in plain English. LeaseLens reads your lease (PDF or Markdown), answers questions about specific clauses, and highlights the terms most worth double-checking before you sign, renew, or move out.

Built with Flask and an OpenAI-compatible model API (currently [Groq](https://console.groq.com)).

## Features

- **Ask questions in plain English** — "Can I have a pet?", "What's the late fee?", "Can I leave before my lease ends?" Answers cite the page number they came from.
- **Automatic summary** — rent, deposit, lease start/end dates, late fee, and move-out notice period, extracted the moment you upload.
- **Risky clause scanner** — on-demand scan for early-termination fees, automatic renewals, indemnity clauses, attorney-fee shifting, and similar terms, ranked High/Medium/Low.
- **Non-lease warning** — a quick keyword check flags files that don't look like a lease, so you don't get a confident summary of the wrong document.
- **Clickable page citations** — click any "(p. 3)" in an answer to open that page's actual extracted text next to it.
- **Suggested questions** — one-tap buttons for common questions if you're not sure what to ask.
- **Downloadable report** — saves the summary, flagged clauses, and full Q&A history as a text file.
- **Key dates & calendar export** — works out your notice deadline from the lease end date and generates a `.ics` file with reminders.
- **Renewal offer comparison** — upload a renewal/extension offer and see rent, fees, and terms compared side by side against your current lease.
- **Per-browser sessions** — each visitor's uploads and history are private to their own browser session.

## Setup

Requires Python 3.9+.

    git clone https://github.com/aarchie25/leaselens.git
    cd leaselens
    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt

You'll need an API key from an OpenAI-compatible provider. This project defaults to [Groq](https://console.groq.com/keys), which has a free tier.

    export GROQ_API_KEY="your-key-here"

## Running it

    python src/app.py

Then open **http://127.0.0.1:5000** in your browser.

To use a different port:

    python src/app.py --port 8080

### Optional environment variables

| Variable | Purpose | Default |
|---|---|---|
| `GROQ_API_KEY` | Your API key | — |
| `LLM_MODEL` | Model to use | `openai/gpt-oss-120b` |
| `LLM_BASE_URL` | API base URL, for a different provider | `https://api.groq.com/openai/v1` |
| `FLASK_SECRET_KEY` | Signs session cookies; set this for a stable key across restarts | random each run |

Example using a smaller, faster model:

    LLM_MODEL=openai/gpt-oss-20b python src/app.py

## Known limitations

- **Scanned (image-only) PDFs aren't supported.** The lease needs a text layer to extract from.
- **Nothing is saved to disk.** Uploaded leases and results live in server memory and are cleared when the server restarts.
- **Sessions, not accounts.** Each browser gets a private cookie, not a login — there's no username or password.
- **Rate limits apply.** Free-tier API keys have per-minute and per-day token limits. If you see a usage-limit message, wait the stated time and try again.
- **This is not legal advice.** Summaries, risk flags, and comparisons are generated by an AI model from a subset of the lease's pages and can miss or misread clauses. Always check the cited page yourself before relying on an answer.
